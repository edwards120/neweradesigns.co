# DeepSeek Entry Instructions

Before reviewing an isolated code problem in this repository:

1. Read `AGENTS.md`.
2. Read `docs/CODE_COMMENT_STANDARD.md`.
3. Read the relevant file excerpts and do not invent missing repository context.
4. Use `docs/AI_WORKFLOW_AND_BUILD_SEQUENCE.md` to understand where the task belongs in the overall build.

DeepSeek is primarily being used here for narrow technical exploration, alternate implementations, code explanation, edge cases, and test ideas.

For every proposal, include:

- The problem being solved
- The smallest relevant file set
- Two implementation options when tradeoffs matter
- Shopify, browser, accessibility, and performance risks
- Tests or validation steps
- Any assumptions that require repository verification

Do not publish the theme, provide credentials, create front-end password security, or make broad architectural changes from a small pasted excerpt.
