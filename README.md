**New Era Designs**

This is the working Shopify theme behind New Era Designs—my portfolio, podcast home, case-study archive, client experience, and honestly my digital design playground.

I’m a designer first, so I never wanted the site to feel like I picked a template, changed the colors, and called it branding. The goal is to create an actual world around the work: sharp but imperfect, luxurious without being cold, historical and modern, masculine and feminine, serious but still strange enough to feel alive.

I’m also learning more of the technical side while I build, so this repository shows both the finished experience and the process behind it. Some parts are polished, some are experiments, but the direction is intentional.

The theme includes custom Shopify sections, editorial layouts, motion systems, portfolio cases, podcast content, client-facing pages, and interactive elements created specifically for New Era Designs.


New Era Designs began as a product-focused brand and is now evolving into a creative studio specializing in **brand identity, websites, spatial design, motion, and visual storytelling**.
This repository contains the working code behind **neweradesigns.co**—including the portfolio, case studies, podcast experience, client resources, custom animations, and interactive Shopify features.


### The Current Era

**Version 2.0** marks the transition from primarily selling apparel to providing design services. Older shirt collections are currently being archived as the website is rebuilt, refined, and repositioned—though selected products may return in a future release.
