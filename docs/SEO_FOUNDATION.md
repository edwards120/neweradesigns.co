# New Era Designs — SEO Foundation

> Search optimization should make the studio easier to understand. It should not flatten the brand into repetitive keywords or promise “perfect” rankings that nobody can guarantee.

---

## Core search positioning

New Era Designs should consistently describe itself around this central territory:

**Brand identity, wayfinding, signage, environmental graphics, spatial design, and visual storytelling for businesses and built environments.**

### Primary topic groups

- Environmental graphic design
- Wayfinding design
- Signage design and sign systems
- Brand identity systems
- Branded environments
- Spatial and experiential graphic design
- Houston graphic and environmental design
- Fabrication-aware design
- Retail, hospitality, workplace, and property design communication

Use these phrases naturally where they help visitors. Do not force every phrase onto every page.

## Case-study SEO structure

Each case should use a specific title rather than only a project name.

### Recommended title pattern

```text
[Project Name] | [Primary Discipline] Case Study | New Era Designs
```

Examples:

```text
The Rice Box | Environmental Graphics Case Study | New Era Designs
The Burger Joint | Signage and Brand Experience | New Era Designs
Houstonian Hotel Concept | Wayfinding and Spatial Identity Study
```

### Recommended case description pattern

```text
A case study exploring [problem], [primary design response], and [meaningful technical or strategic detail] for [client, location, or project type].
```

### Every complete case should include

- One unique H1
- A short project summary
- Project type and location when public
- Disciplines involved
- The original problem
- Constraints
- The design response
- Technical or production considerations
- Outcome or honest project status
- Descriptive image alternative text
- Links to relevant services
- A contact or next-project action

---

## Image alternative-text standard

Alternative text should describe the useful content of an image—not repeat the filename or stuff keywords.

Weak:

```text
signage graphic design Houston sign company image
```

Better:

```text
Illuminated red channel-letter sign mounted above The Rice Box storefront at night.
```

For decorative textures, flourishes, and repeated background imagery, use empty alternative text when appropriate so assistive technology can ignore them.

## URL structure

Keep handles clear and durable:

```text
/pages/cases
/pages/services
/pages/info
/pages/podcast
/pages/contact
/pages/cases/rice-box
```

Avoid handles such as:

```text
/pages/new-page-final-2
/pages/services-copy
/pages/website-2026-update
```

When changing an existing public URL, create an appropriate redirect rather than silently breaking incoming links.

## Internal linking plan

The site should create a connected system rather than isolated pages.

### Home should link to

- Selected Work
- Services
- Contact
- One featured case
- Podcast or Info as a secondary path

### Services should link to

- Relevant cases
- Process
- Contact

### Cases should link to

- Related service
- Another relevant case
- Contact

### Podcast should link to

- Related cases or essays
- Info
- Subscription platforms

### Info should link to

- Selected Work
- Services
- Contact

Use descriptive link language. “View the Rice Box environmental graphics case” is more useful than repeating “Click here.”

## Social-sharing foundation

Every major page should have:

- A specific Open Graph title
- A useful Open Graph description
- A correctly cropped sharing image
- The canonical page URL
- The correct site name

Recommended sharing-image direction:

- Strong project image or authored editorial composition
- Minimal embedded text
- Consistent New Era Designs framing
- Legible at small preview sizes
- No confidential client information

---

## Local relevance

Houston should appear naturally in:

- Homepage studio description
- About page
- Contact page
- Public case locations
- Appropriate page metadata

Do not insert “Houston” into every heading solely for ranking. The site should remain credible to national and remote clients while making the studio’s location clear.

---

## Content that can build search authority over time

- Complete case studies
- Field notes on signage and wayfinding decisions
- Podcast transcripts or structured episode notes
- Articles explaining fabrication-aware design
- Accessibility and navigation observations
- Before-and-after project reasoning
- Houston design and built-environment commentary
- Clear documentation for tools such as SignSpec Studio

The strongest SEO strategy for this studio is not a hidden list of keywords. It is publishing clear, specific evidence of expertise.
