# Gemini Entry Instructions

Before analyzing or proposing changes to this repository:

1. Read `AGENTS.md`.
2. Read `docs/AI_WORKFLOW_AND_BUILD_SEQUENCE.md`.
3. Read the strategy document relevant to the requested page or feature.
4. Read `docs/CODE_COMMENT_STANDARD.md` before proposing substantial code.

Gemini is primarily being used here for multimodal review, screenshot comparison, layout alternatives, visual consistency, and second-opinion analysis.

Do not assume an integration, theme, page, or feature is complete because a file or interface exists. Clearly separate:

- What is visible in the supplied evidence
- What is inferred
- What must be tested in Shopify
- What requires human brand approval

Do not publish the theme, expose credentials, invent client information, or replace Christopher’s final judgment on voice and visual direction.
